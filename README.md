# 高等数学 I 每周讲义

欢迎来到上海科技大学《高等数学 I》习题课讲义页面。

本讲义供习题课使用，共计 **16 讲**，将按照课程进度逐周发布。请同学们在习题课前先独立思考并完成讲义中的题目，再在课上结合讲解订正、补充和整理。

## 📚 查看讲义

👉 [进入已发布讲义目录](published/README.md)

进入目录后，点击对应讲次的 PDF 文件即可在线阅读。如需在电脑、手机或平板上保存，可以在 PDF 页面选择下载。
